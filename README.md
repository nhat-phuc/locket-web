# Locket Web - Full Stack Structure

Đây là bộ khung cấu trúc Next.js + TypeScript cho website động.

## Công nghệ dự kiến
- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL
- Authentication
- Payment API/Webhook
- Admin Dashboard

Các file `page.tsx`, API route và schema có thể được triển khai ở bước tiếp theo.
